# 📄 Azure Data Factory Project II — Study Notes

This folder contains the detailed study notes and architecture 
reference document for the Azure Data Factory Project II.

## 📋 What's Inside

**Azure_Data_Factory_II.pdf** — A comprehensive, hands-on walkthrough 
document covering:

- Architecture diagrams for each pipeline
- Step-by-step ADF configuration screenshots
- Integration Runtime setup with authentication keys
- Linked Service connection troubleshooting
- Watermark/incremental load implementation details
- Dynamic expression breakdowns with plain-English explanations
- SQL query previews and pipeline debug outputs
